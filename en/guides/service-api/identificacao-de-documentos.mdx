title: Identification documents

---

Use `SERVICE_OCR` to extract data from identification documents such as RG, CNH, OAB, RNE, and PASSPORT.

## RG / CIN


Payload:

```json
{
  "service": "SERVICE_OCR",
  "documentType": "RG",
  "image1": "FRONT_BASE64",
  "image2": "BACK_BASE64"
}
```

Expected response:

```json
{
  "result": {
    "cpf": "00000000000",
    "docType": "RG/CIN",
    "name": "EXTRACTED NAME",
    "fatherName": "FATHER'S NAME",
    "motherName": "MOTHER'S NAME",
    "birthDate": "yyyy-mm-dd",
    "rg": "000000000", // <- RG document only
    "rgIssuer": "SSP/UF",
    "rgIssueDate": "yyyy-mm-dd",
    "nationality": "BRA", // <- CIN document only
    "validDate": "yyyy-mm-dd", // <- CIN document only
    "naturality": "CITY/STATE",
  },
  "status": {
    "code": 200,
    "message": "OCR realizado com sucesso"
  },
  "onboardingStatus": "APPROVED",
  "externalId": "..."
}
```

## Automatic identification

This type of OCR identifies the document by inference and extracts the
corresponding data from the identified document.

Payload:

```json
{
  "service": "SERVICE_OCR",
  "documentType": "IDENTIFICATION_DOCUMENT",
  "image1": "DOCUMENT_FRONT_BASE64",
  "image2": "DOCUMENT_BACK_BASE64" // <- Optional
}
```

Expected response:

```json
{
  "result": {
    // Depends on the identified document type.
  },
  "status": {
      "code": 200,
      "message": "OCR realizado com sucesso"
  },
  "onboardingStatus": "APPROVED",
  "externalId": "..."
}
```

For now, this page covers RG, CNH, OAB, RNE, and PASSPORT. Other documents
should be validated once OCR support is finalized for each type.

## Expected fields by return

| DocumentType | Returned fields | Notes |
| --- | --- | --- |
| RG | `cpf`, `docType`, `name`, `birthDate`, `fatherName`, `motherName`, `rg`, `rgIssuer`, `rgIssueDate`, `nationality`, `naturality`, `validDate` | If the document sent is a `CIN`, it may include `nationality` and `validDate`, and not include `rg`.<br /> Send front and back of the document |
| CNH | `cpf`, `docType`, `name`, `birthDate`, `fatherName`, `motherName`, `cnhCategory`, `cnhNumber`, `validDate`, `emissionPlace`, `rg`, `rgIssuer`, `cnhIssueDate`, `cnhDocEmissionPlace`, `cnhFirstQualificationDate`, `cnhLastEmissionDate`, `renach`, `paidActivity`, `state` | Single document upload |
| OAB | `cpf`, `docType`, `name`, `birthDate`, `fatherName`, `motherName`, `rg`, `issueDate`, `naturality`, `registrationNumber`, `isOrganDonor`, `via`, `observations` | Send front and back of the document |
| RNE | `cpf`, `docType`, `name`, `birthDate`, `fatherName`, `motherName`, `rneNumber`, `rnmNumber`, `nationality`, `issueDate`, `classification`, `entryDate`, `naturality`, `sex`, `via`, `rneValidDate`, `issueBody`, `residencePeriod` | Fields exclusive to `RNE`: `entryDate`, `naturality`, `via`, `rneNumber`.<br /> Fields exclusive to `CRNM`: `rnmNumber`, `cpf`, `residencePeriod`. <br /> Send front and back of the document |
| PASSAPORT | `docType`, `name`, `fatherName`, `motherName`, `birthDate`, `nationality`, `validDate`, `issueDate`, `naturality`, `sex`, `issueCountry`, `passaportType`, `passaportNumber`, `authority` | Single document upload |
| IDENTIFICATION_DOCUMENT | Depends on the document identified internally | The OCR text is analyzed to infer whether the document is a CNH, RG, OAB, RNE, or Passport.<br /> In this case, sending the back of the document, `image2`, is optional. |

Missing fields shouldn't show up as `null` just to fill out the contract.
The Service API's public standard is to return only useful data.

<Note>
For questions about the API's return, see [Questions and Support](/en/guides/service-api/duvidas-e-suporte).
</Note>
