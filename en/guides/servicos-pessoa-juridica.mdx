# Business Services

Business services let you query, validate, and enrich CNPJ data across PJ
onboarding flows, registration analysis, business KYC, business owner
assessment, tax standing, debts, protests, and compliance.

Just like individual services, all of them run through the central
services endpoint. The `service` field defines which product will be
processed.

Before building the body, check the client's product to see which alias is
enabled. That's the value that should go in the `service` field.

```http
POST /api/service-api
```

In the `curl` examples, `{base_url}` represents the URL of the chosen
environment:

| Environment | Base URL |
| --- | --- |
| Staging | `https://backoffice-hml.idcerberus.com` |
| Production | `https://backoffice.idcerberus.com` |

Example request:

```json
{
  "service": "SERVICE_CORPORATE_DATA_ENRICHMENT",
  "cnpj": "cnpj"
}
```

## CNPJ on-demand query

The `SERVICE_RFB_PJ_ON_DEMAND` service runs the CNPJ query at the Federal
Revenue in on-demand mode. Use it when the integration needs to fetch or
update the company's registration information directly at request time.

```json
{
  "service": "SERVICE_RFB_PJ_ON_DEMAND",
  "cnpj": "cnpj"
}
```

Example response:

```json
{
  "result": {
    "cnpj": "00000000000000"
  },
  "status": {
    "code": 200,
    "message": "Success"
  }
}
```

<Note>
  This service runs the on-demand query, but the response currently exposed
  can be minimal. For a more complete registration view of the company, also
  use `SERVICE_CORPORATE_DATA_ENRICHMENT`.
</Note>


### SINTEGRA query

The SINTEGRA query looks up information in the Integrated System for
Information on Interstate Goods and Services Operations, on the official
government site. SINTEGRA tracks interstate operations carried out by ICMS
taxpayers and helps businesses issue invoices for customers.

```json
{
  "service": "SERVICE_SINTEGRA_CONSULTATION",
  "cnpj": "cnpj",
  "uf": "uf"
}
```

Main response fields:

| Field | Description |
| --- | --- |
| `result.cnpj` | CNPJ |
| `result.status` | CNPJ status in SINTEGRA |
| `result.uf` | CNPJ's state |
| `result.cfdf` | Federal District Tax Registration, exclusive to companies registered in the DF |
| `result.origin` | Source of the information |
| `status.code` | Status message code |
| `status.message` | Status code message |

Example request:

```bash
curl --location '{base_url}/api/service-api' \
  --header 'Content-Type: application/json' \
  --data '{
    "service": "SERVICE_SINTEGRA_CONSULTATION",
    "cnpj": "cnpj",
    "uf": "uf (optional)"
}'
```

Example response:

```json
{
  "result": {
    "cnpj": "30108283000000",
    "status": "NOT REGISTERED",
    "uf": "DF",
    "cfdf": "0785286100111",
    "origin": "Sintegra"
  },
  "status": {
    "code": 200,
    "message": "Success"
  }
}
```

### Extended business addresses

Returns the complete list of addresses associated with the queried CNPJ
(current and historical), with normalized data on street, neighborhood,
city, state, country, postal code, and address type, plus an aggregated
summary with totals and pass-through dates. Use this query when the
registration analysis needs to go beyond the main address returned by
basic CNPJ queries.

```json
{
  "service": "SERVICE_ADDRESSES_EXTENDED_CNPJ",
  "cnpj": "cnpj"
}
```

Main response fields:

| Field | Description |
| --- | --- |
| `result.cnpj` | Queried CNPJ |
| `result.addresses` | List of addresses associated with the company (all values come as text/string) |
| `result.addresses.address` | Street address |
| `result.addresses.number` | Number |
| `result.addresses.complement` | Complement, when present |
| `result.addresses.neighborhood` | Neighborhood |
| `result.addresses.city` | City |
| `result.addresses.state` | State |
| `result.addresses.country` | Country |
| `result.addresses.zipcode` | Postal code |
| `result.addresses.addressType` | Address type (e.g., `COMMERCIAL`, `RESIDENTIAL`) |
| `result.addresses.isActive` | `"true"`/`"false"`, indicates whether the address is currently active |
| `result.addresses.isMainForEntity` | `"true"`/`"false"`, indicates whether it's the company's main address |
| `result.addressesExtendedTotal` | Total number of addresses found |
| `result.addressesExtendedTotalActive` | How many are active |
| `result.addressesExtendedOldestPassageDate` / `result.addressesExtendedNewestPassageDate` | Date of the oldest and most recent pass-through across all addresses |
| `status.code` | Status message code |
| `status.message` | Status code message |

### Business owners' KYC and compliance query

Queries KYC and compliance information for all of the company's business
owners in a single call (individuals and businesses), including political
exposure (PEP) and sanctions on national and international restrictive
lists.

```json
{
  "service": "SERVICE_COMPANY_KYC_OWNERS",
  "cnpj": "cnpj"
}
```

Main response fields:

| Field | Description |
| --- | --- |
| `result.totalCurrentPep` | Number of business owners currently classified as PEP |
| `result.totalHistoricallyPEP` | Number of business owners with a PEP history (includes anyone who was PEP and no longer is) |
| `result.totalCurrentSanctioned` | Number of currently sanctioned business owners |
| `result.totalHistoricallySanctioned` | Number of business owners with a sanctions history |
| `result.averageSanctionsPerOwner` | Average number of sanctions per business owner (rounded) |
| `result.pepPercentage` | Percentage of business owners classified as PEP |
| `result.kycOwners` | Combined list with the KYC breakdown for each business owner (individuals and businesses) |
| `result.companyOwners` / `result.peopleOwners` | The same breakdown as `kycOwners`, but already split into business and individual owners |
| `kycOwners[].isPep` | Indicates whether the business owner is currently PEP |
| `kycOwners[].isCurrentlySanctioned` | Indicates whether the business owner is currently sanctioned |
| `kycOwners[].sanctionsHistory` | The business owner's full sanctions history |
| `kycOwners[].highConfidenceSanctionsHistory` | The same history, filtered to a `matchRate` above 90; use this list for automated decisions |
| `kycOwners[].pepHistories` | The business owner's history of positions and political exposure |

There's no `partnersHistory` field in this service's return. The
per-business-owner breakdown comes in `kycOwners` (or
`companyOwners`/`peopleOwners`).
