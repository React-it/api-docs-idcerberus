# Service matrix

This matrix helps you quickly find which service to use before opening the
full payload in the API Reference.

<Info>
  This page is a shortcut by goal. The full technical catalog, with every
  field and example for each service, lives in
  [Individual Services](/en/guides/servicos-pessoa-fisica) and
  [Business Services](/en/guides/servicos-pessoa-juridica). Use them as the
  reference source when you need a service's full contract.
</Info>

<Tip>
  Every item below runs through `POST /api/service-api`, except the
  authentication, onboarding, and customer endpoints. On the central
  endpoint, the `service` field picks the product.
</Tip>

## Individuals

  OCR services are listed in this matrix, but the full payloads are in the
  [OCR via Service API](/en/guides/service-api/sobre-ocr-service-api) guide. Use

  URL, or `documentType`.
</Info>

## Flows outside service-api

| Goal | Endpoint | When to use |
| --- | --- | --- |
| Generate JWT token | `POST /api/token-generate` | Before protected calls |
| Generate onboarding token | `POST /api/token-history-onboarding` | Before starting SDK integration |
| Query onboarding | `GET /api/onboarding/report/{tokenOnboarding}` | To retrieve the structured JSON result |
| Download onboarding report | `GET /api/history-onboarding-report/{tokenOnboarding}` | To get the final PDF |
| Query customer | `GET /api/customer` | To locate a customer by CPF or CNPJ |
| Change customer status | `POST /api/changeStatusOfCustomer` | To activate or deactivate a customer |
