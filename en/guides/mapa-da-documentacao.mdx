## Recommended path

<Steps>
  <Step title="Read the Quickstart">
    Understand the basic flow: generate a token, run a service, and read the response.
  </Step>
  <Step title="Make a first query">
    Choose CPF or CNPJ and run the complete example.
  </Step>
  <Step title="Choose the real service">
    Use the service-selection page to find the `service` code.
    If the test involves a document, image, or base64, also open the OCR guide.
  </Step>
  <Step title="Copy the technical contract">
    Open the API Reference to copy the request, response, and schemas.
  </Step>
  <Step title="Prepare for production">
    Review best practices, environments, error handling, and troubleshooting.
  </Step>
</Steps>
