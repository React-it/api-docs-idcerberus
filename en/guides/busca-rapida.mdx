# Quick search

Use this page when you don't know exactly where to look. It gathers the
terms that best help the documentation's search find the right guide, the
correct service, or a ready-made example.

<Info>
  This page is a list of terms to type into the search box. If you want a
  path guided by role or goal instead of searching, see
  [Documentation map](/en/guides/mapa-da-documentacao).
</Info>

## Ready-made search questions

You can search whole phrases:

1. `How do I call SERVICE_OCR in /api/service-api?`
2. `What payload for OCR of front and back RG?`
3. `How do I test SERVICE_FACE_INDEX in staging?`
4. `Don't have access to the service`
5. `Why did result come back empty?`
6. `Which service should I use for PJ credit risk?`
7. `How do I query a CNPJ card via OCR?`
8. `What are the required fields for SERVICE_CREDIT_RISK_COMPANY?`

## If the search doesn't find it

1. Search by the full alias, for example `SERVICE_OCR`.
2. Search by the document or data point, for example `CNH`, `CNPJ`, `score`, `phone`.
3. Search by the problem, for example `missing image`, `empty result`, `no access`.
4. Open the [service index](/guides/indice-de-services) and use `Ctrl + F`.
5. If it still doesn't show up, confirm whether the service is already documented or enabled for the API.
