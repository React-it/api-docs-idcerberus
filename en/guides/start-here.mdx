## Before testing

1. Confirm that you have credentials for the selected environment.
2. Generate a token in the same environment as the request.
3. Check that the product has the service enabled for the API.
4. Use valid test data and do not send sensitive data in tickets or logs.
5. Read `result`, `status`, `onboardingStatus` and `externalId` in the response.
