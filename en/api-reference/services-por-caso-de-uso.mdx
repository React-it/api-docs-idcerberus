# Services by use case

Use this page when you know the goal of the integration but do not yet know which `service` to call.

After choosing the service, open the individual or business catalog to copy the full request.
</Info>

## How to choose

1. Start with the goal of the query.
2. Copy the indicated `service`.
3. Open the individual or business catalog to see the payload and return.
4. If it is OCR, check the image guide before testing.
5. If you want a ready-made flow, use [Ready-made recipes](/en/guides/receitas-prontas).
