<Accordion title="CNPJ card OCR" id="SERVICE_OCR_CNPJ_CARD">

**Service:** `SERVICE_OCR_CNPJ_CARD`

**When to use:** Use to extract data from documents sent as base64 or by URL.

**What it returns:** Returns data extracted from the CNPJ card sent as an image, including the CNPJ, document type and OCR text when available.

<CardGroup cols={2}>
 <Card icon="arrow-right-to-bracket" title="Input">
 Required fields: `service`, `image1`.
 </Card>
 <Card icon="list-check" title="Result">
 Main fields in `result`: `cnpj`, `docType`, `genericOcr`.
 </Card>
 <Card icon="circle-info" title="Call status">
 Use `status.code` and `status.message` to understand whether the query processed correctly.
 </Card>
 <Card icon="sliders" title="Optional fields">
 No optional field mapped in this example.
 </Card>
</CardGroup>

**Endpoint:** `POST /api/service-api`

**Required fields:** `service`, `image1`

**Optional fields:** No optional field mapped in this example.

### OCR guide

For ready-made payloads, image quality and error diagnostics, see [OCR via Service API](/en/guides/service-api/sobre-ocr-service-api).

### Minimum payload

```json
{
  "service": "SERVICE_OCR_CNPJ_CARD",
  "image1": "BASE64_DO_CARTAO_CNPJ"
}
```

### Expected clean return

```json
{
  "result": {
    "cnpj": "cnpj",
    "docType": "CNPJ_CARD",
    "genericOcr": "text extracted from the CNPJ card"
  },
  "status": {
    "code": 200,
    "message": "Success"
  },
  "externalId": "{externalId}"
}
```

### Common error

```json
{
  "result": {},
  "status": {
    "code": 400,
    "message": "CNPJ não encontrado no cartão CNPJ"
  },
  "onboardingStatus": "REFUSED",
  "externalId": "{externalId}"
}
```

### Step by step

1. Generate the token at `POST /api/token-generate` and send it in the `Authorization: Bearer {jwt_token}` header.
2. Build the body with the exact `service` and the required fields listed below.
3. Run `POST /api/service-api` in the chosen environment.
4. Check `status.code` and `status.message` to validate the technical processing.
5. Map the `result` fields per the summary and the response example for this service.
