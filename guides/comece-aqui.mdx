## Antes de testar

1. Confirme se você possui credenciais para o ambiente escolhido.
2. Gere um token no mesmo ambiente da chamada.
3. Verifique se o produto possui o service habilitado para API.
4. Use dados de teste válidos e não envie dados sensíveis em chamados ou logs.
5. Leia `result`, `status`, `onboardingStatus` e `externalId` no retorno.
